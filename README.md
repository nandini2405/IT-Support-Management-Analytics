# IT Support Management & Analytics

## Project Overview
This project combines ServiceNow IT support workflows with data analytics to monitor incidents and support performance.

## Technologies Used
- ServiceNow
- SQL Server
- Python
- Pandas
- Power BI

## Project Components
- Incident management and tracking
- Laptop request approval workflow
- Incident data analysis using SQL
- Data cleaning and analysis using Python
- KPI reporting and incident trend visualization using Power BI

## Key Metrics
- Total incidents
- Unresolved incidents
- High-priority incidents
- Average resolution time
- Monthly incident trends

## Project Structure
- `analysis_queries.sql` — SQL analysis queries
- `IT_Support_Analytics_Python.ipynb` — Python data analysis
- Power BI report — interactive incident analytics dashboard

## Note
This project is for learning and demonstration purposes.
